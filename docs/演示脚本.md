# SafeDrop 实操演示脚本

课程讲义第 33 页要求展示编译、部署和测试全过程，第 3 页要求提交实际 MP4。以下约 7 分钟仅作分镜参考，按您掌握的课程网站最新要求调整。录制状态待补，截图与证据可作讲解插图。

## 开拍前

- 使用交付源码在独立目录编译，准备独立 Windows 本机部署或已有的专用临时验证部署。避免使用原卷的正式账号、文件和认证设置。录制前清空剪贴板、关闭通知、使用专用浏览器配置，隐藏书签、系统用户名以及终端历史。
- 用专用临时发送方、接收方、无权第三方和维护员。使用纯文本和可公开的无害二进制样本；录制前在镜头外完成登录资料和 CA 的准备。输入口令、邀请、私钥、MFA 密钥或恢复码时暂停录制，复核所有切换、窗口标题、终端输出和补帧。
- 使用真实扫描器处理无害样本。隔离界面用受控无害状态演示，真实 ClamAV 测试签名的验收引用 Linux CI 结果，现场不创建签名样本。期限演示只动夹具时钟，恢复目标选择不存在的独立目录。公开证据中的截图已裁剪或遮盖可关联字段。

## 实际录制顺序

| 建议时间 | 操作和画面 | 旁白和验收点 |
| --- | --- | --- |
| 00:00–00:50 | 显示源码版本，录制 `npm ci`、`npm run build` 的命令与成功输出，可剪去纯等待 | 报告代码基线、交付提交与各自 CI。编译与部署结果应在同一段实录可追溯。 |
| 00:50–01:30 | 按复现说明启动专用环境，从 Windows 浏览器打开 HTTPS 入口；在另一终端执行 `npm run security:report` | 展示 URL、应用就绪和安全报告输出。说明首次 CA 信任的来源，终端不要展示凭据文件。 |
| 01:30–02:50 | 发送方并发上传无害文件，暂停并恢复较大文件；扫描通过后交付，接收方正常下载；对源和保存件运行 `Get-FileHash -Algorithm SHA256` | 展示两个任务的独立进度、接收结果及相等摘要。分别从下载/续传按钮操作时，以界面实际结果为准。 |
| 02:50–03:25 | 第三方查看收件列表；打开报告中权限拒绝的对应测试结果 | 界面展示第三方看不到授权；服务端越权拒绝由隔离协议测试反馈取证。仅凭列表缺失不能断言 API 拒绝。 |
| 03:25–04:10 | 扫描夹具对比“已隔离”和“扫描通过”；指出隔离项下载/交付不可用，同屏标示“受控界面状态” | 引用真实引擎 CI 的隔离与重启 PASS 行，分别说明界面和引擎证据。 |
| 04:10–04:55 | 在专用期限夹具中先拍可下载及旧无期限授权，再应用夹具时钟标记，刷新显示已到期 | 展示后续服务端读取受拒依据。说明已保存内容仍可访问，旧授权保留无期限语义。 |
| 04:55–05:55 | 临时维护员创建加密副本；终端用受保护副本和可信独立检查点执行离线校验与隔离恢复 | 只展示校验状态、SQLite 完整性及恢复路径别名。说明副本、检查点和密钥各自保管。 |
| 05:55–07:00 | 展示时间线桶、缩放、平移、分页和详情；普通账号与临时管理员分别比对范围 | 说明完整范围统计和快照游标。可插入已审查的桌面/移动图，标注历史 Edge 夹具画面。 |

## 可复用启动入口

- 常规路径见[运行与验收](运行与验收.md)和[交付与复现](交付与复现.md)。先在独立目录安装并编译，独立回环 ClamAV 就绪后录制正常传输。
- 扫描夹具：`npx --no-install tsx tests/scans-browser-fixture.ts`，默认回环 1603。演示夹具用 `CLAMD_REAL_HOST`、`CLAMD_REAL_PORT` 指向真实回环 ClamAV，默认 127.0.0.1:3429。合成隔离行由脚本预置，真实无害件状态由扫描器产生。
- 期限夹具：`npx --no-install tsx tests/delivery-expiry-browser-fixture.ts`，默认回环 1604，同样需真实引擎。在它刚输出的新临时夹具根中创建空的 `simulate-expiry` 标记，仅推进该夹具的交付时钟两小时。结束时可移走本次自行创建的标记，保持服务器系统时间和已有测试历史。
- 备份夹具：`npx --no-install tsx tests/backup-browser-fixture.ts`，默认回环 1602，生成独立账号、无害文件和备份密钥。在夹具浏览器中先从审计页导出并独立保存检查点，再由维护页创建副本；离线 verify/restore 按[恢复说明](存储维护与恢复.md)执行，恢复到夹具之外且不存在的目录。远程维护 CLI 的 status、anchor、backup 操作需要严格 HTTPS，可在真实临时部署使用。
- 时间线夹具：`node tests/events-browser-fixture.mjs`，默认回环 1605，使用编译后的服务和 420 条合成审计。夹具 HTTP 适用界面镜头，HTTPS/WSS 证明来源于正常部署和自动验收。

如果无法实时显示某项，使用有来源和环境字幕的静态画面或精简证据，保留该项本次未实录的状态。公开素材分别为 `events-desktop.png`、`events-mobile.png`、`scan-fixture.png`、`expiry-fixture.png`、`encrypted-backup-fixture.png`，随独立证据 ZIP 交付。录制后从头检查文件能播放、姓名学号命名正确、关键操作和声音清楚，且无凭据和正式数据入镜。
